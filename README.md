**EFTarkov Buddy** is a fast, lightweight, and modern desktop companion application designed for *Escape From Tarkov*. Built with **Tauri v2** and **Rust**, it helps PMC operatives track quest progression, story chapters, hideout module requirements, and physical item needs in real time.

---

## 🚀 Key Features

* 📜 **Quest & Main Story Tracker**: Complete database of side quests and 1.0 main story chapters, neatly organized by Traders and Maps.
* 🏠 **Hideout Module Manager**: Keep full control of module upgrade paths and requirements to level up your Hideout efficiently.
* 📦 **Smart Item Tracker**: Automatically calculates all required physical items for pending quests and hideout upgrades while filtering out objective action verbs.
* 🗺️ **High-Res Interactive Maps**: View detailed map locations alongside essential key lists with direct links to the official Tarkov Wiki.
* 👤 **PMC Profile & Trader Progression**: Track your level, loyalty levels, and reputation across all traders in one centralized dashboard.
* 💾 **Wipe / Prestige Reset & Backups**: Easily export and import your progress via JSON backups or trigger a full wipe reset for new seasons.

---

## 💻 Tech Stack

* **Frontend**: HTML5, Modern CSS, Vanilla JavaScript
* **Backend**: Rust
* **Framework**: Tauri v2
* **Data Format**: Lightweight JSON local databases

---

## 📦 Installation

1. Go to the [Releases](../../releases) section of this repository.
2. Download the latest installer (`EFTarkov_Buddy_1.0.0_x64-setup.exe`).
3. Run the installer and follow the setup wizard.
4. Launch **EFTarkov Buddy** and start tracking your raid goals!
